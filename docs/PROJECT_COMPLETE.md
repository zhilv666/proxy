## 🔧 核心功能

### 1. 代理配置管理
```bash
proxy config set host 127.0.0.1
proxy config set port 7890
proxy config get host
proxy config list
```

### 2. 命令别名系统
```bash
proxy alias add windows ll "ls -l"
proxy alias add linux ll "ls -lh"
proxy alias add all gs "git status"
proxy alias list
proxy alias remove windows ll
```

### 3. 代理执行
```bash
proxy curl https://google.com
proxy git clone https://github.com/user/repo
proxy npm install
```

### 4. 别名使用
```bash
proxy ll    # 自动展开为 ls -l
proxy gs    # 自动展开为 git status
```

## 💡 技术亮点

1. **零外部依赖**
   - 完全使用 Zig 标准库
   - 无需安装第三方包

2. **跨平台实现**
   - 统一的命令行接口
   - 自动处理平台差异
   - Windows UTF-8 编码自动配置

3. **智能别名系统**
   - 平台特定别名（windows/linux/macos）
   - 跨平台别名（all）
   - 优先级：当前平台 > all

4. **配置持久化**
   - JSON 格式，人类可读
   - 存储在 `~/.proxy/`
   - 配置文件和别名文件分离

5. **UTF-8 完整支持**
   - 中文帮助正常显示
   - Windows 控制台自动设置 CP65001
   - 所有平台统一编码
